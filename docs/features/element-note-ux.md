# ElementNote 편집 화면과 설정

편집 화면은 맨 위의 **탭 줄**, 왼쪽의 **캔버스**, 오른쪽의 **사이드바**로 나뉩니다.

## 탭과 뷰

창의 제목 표시줄에 브라우저처럼 탭이 두 개 있습니다. 빈 곳을 끌면 창이 움직입니다.

| 자리           | 하는 일                                                                    |
| -------------- | -------------------------------------------------------------------------- |
| 탭 (손, 발)    | 편집 화면을 그 뷰로 바꿉니다. 캔버스와 사이드바가 함께 바뀝니다.           |
| 탭 줄 오른쪽   | 얼불춤 연결 상태(누르면 설정의 **보여 줄 곳**이 열립니다), **설정**        |
| 캔버스 왼쪽 위 | 지금 뷰에 띄운 키뷰어 이름과 ⌄가 적힌 버튼. 누르면 다른 키뷰어를 고릅니다. |

- 탭은 뷰를 바꾸기만 합니다. 손과 발 키뷰어는 항상 함께 떠 있고, 탭에는 각 뷰에 띄운 키뷰어 이름이 작게 보입니다.
- 뷰에 띄울 키뷰어를 바꾸는 것은 캔버스 왼쪽 위의 버튼(예: **16K ⌄**) 하나뿐입니다.

## 키뷰어 고르기

캔버스 왼쪽 위의 키뷰어 버튼을 누르면 그 뷰(손 또는 발)용으로 만든 키뷰어가 실제 모습 그대로 나옵니다. 카드는 창 너비를 남김없이 나눠 쓰고, 지금 떠 있는 것은 테두리로 표시됩니다.

- 그림을 누르면 그 키뷰어가 뜨고 캔버스에 열립니다.
- 그림을 끌면 순서가 바뀝니다. Alt+←/→로도 옮길 수 있습니다.
- **새 키뷰어** 칸을 누르면 그 칸에서 바로 이름을 적습니다. Enter로 만들고 Esc로 그만둡니다.
- 이름 옆의 ⋯에 이름 바꾸기, 파일로 저장, 파일에서 불러오기, 누른 횟수 0으로, 처음 상태로 되돌리기, 삭제가 있습니다. 이름 바꾸기도 카드에서 바로 적습니다.

### 파일로 저장하고 불러오기 (프리셋)

키뷰어를 파일로 주고받는 것은 모두 이 화면에서 합니다.

| 어디서                  | 하는 일                                                      |
| ----------------------- | ------------------------------------------------------------ |
| 카드의 ⋯                | **파일로 저장**: 그 키뷰어 하나를 파일로 저장합니다.         |
| 카드의 ⋯                | **파일에서 불러오기**: 파일의 내용으로 그 키뷰어를 바꿉니다. |
| 오른쪽 위 전체 저장     | 손과 발의 모든 키뷰어와 설정을 파일 하나에 담습니다.         |
| 오른쪽 위 전체 불러오기 | 파일에 담긴 모든 키뷰어와 설정으로 바꿉니다.                 |

## 사이드바

사이드바는 항상 켜져 있고 캔버스를 가리지 않습니다. 왼쪽 가장자리를 끌면 너비가 바뀌고, 두 번 누르면 기본 너비로 돌아옵니다. 사이드바에는 요소에 관한 것만 있습니다.

아무것도 고르지 않았을 때는 **요소** 페이지입니다.

- **요소 추가**: 키, 통계, 그래프, 노브, 이미지를 캔버스에 추가합니다. 지금 보이는 화면 한가운데에서 가장 가까운 빈자리에 놓이고, 바로 선택되어 꾸밀 수 있습니다.
- 그 아래는 이 키뷰어의 요소 목록입니다. 줄마다 그 요소가 캔버스에서 보이는 모습(키라면 연결한 키 이름까지)이 작게 그려져 있어, 이름이 아니라 모습으로 찾을 수 있습니다. 줄을 누르면 그 요소의 페이지가 열립니다.
- 줄 왼쪽의 점 여섯 개는 끌어서 순서를 바꿀 수 있다는 표시입니다.
- 목록이 길면 아래에 **아래에 N개 더** 버튼이 나타납니다. 누르면 그만큼 내려갑니다.
- Ctrl(⌘)이나 Shift를 누른 채 여러 줄을 고른 뒤 제목 옆의 **N개 꾸미기**를 누르면 함께 바꿉니다.
- 통계, 그래프, 노브, 이미지, 그룹의 이름은 이 목록에서 줄을 우클릭해 바꿉니다. 키는 연결한 키보드 키가 곧 이름이어서 따로 이름을 붙이지 않습니다.

줄을 누르면 그 안으로 들어가고, 왼쪽 위의 이름을 누르면 한 단계 위로 돌아옵니다. 돌아오면 보던 위치가 그대로입니다.

## 키 꾸미기

캔버스나 목록에서 키를 고르면 그 키의 페이지가 열립니다. 값 하나짜리는 그 자리에서 바로 고치고, 설정이 많은 부분만 줄을 눌러 들어갑니다.

모든 줄은 같은 모양입니다. 왼쪽에 그림 칸, 이름, 오른쪽에 값이나 고치는 칸이 있습니다. 모양을 바꾸는 부분(모양과 색, 글자, 레이닝, 횟수, 고스트 키)의 그림 칸에는 지금 그 키가 그 부분을 단 모습이 실제 색과 글꼴로 작게 그려집니다. 색을 바꾸면 그림도 바로 바뀌어서, 색 견본을 따로 두지 않습니다. 보이는 모습이 없는 부분(입력, 위치, 크기, 소리)은 아이콘입니다. 아직 아무 색도 없는 고스트 키처럼 보이는 것이 없으면 점선 윤곽으로 그립니다.

| 줄        | 하는 일                                                     |
| --------- | ----------------------------------------------------------- |
| 입력      | 버튼을 누른 뒤 연결할 키보드 키를 누릅니다. 그 자리에서 끝. |
| 위치      | X, Y 숫자를 그 자리에서 고칩니다.                           |
| 크기      | W, H 숫자를 그 자리에서 고칩니다.                           |
| 모양과 색 | 배경색, 테두리, 모서리, 이미지 (들어가서 고침)              |
| 글자      | 키에 쓸 글자와 글꼴 (들어가서 고침)                         |
| 레이닝    | 키를 누른 시간만큼 길어지는 효과의 위치·색·빛               |
| 횟수      | 누른 횟수를 보여 주는 숫자의 위치·색·글꼴·움직임            |
| 소리      | 키를 누를 때 나는 소리와 크기                               |
| 고스트 키 | 같은 자리에 겹쳐 보일 두 번째 키                            |

- **항목 페이지**: 설정은 주제별 판(카드)에 묶여 있습니다. 판 이름이 바로 위에 있고, 판 안에서는 한 설정이 한 줄입니다(슬라이더도 숫자 옆 같은 줄). 판 안의 값은 상자가 아닌 글자이고, 가리키면 그 자리에서 고칠 수 있게 바뀝니다. 몇 가지 모양 중 하나를 고르는 설정(레이닝이 키 위 어디서 올라가는지, 횟수를 어디에 둘지)은 결과를 그린 그림 버튼으로 고릅니다. 그림 버튼에 마우스를 올리면 누르기 전에 캔버스의 그 요소가 그 모습으로 보이고, 떼면 원래대로 돌아옵니다. 누를 때만 저장되며, 올려 보기만 한 것은 저장되지도 되돌리기 기록에 남지도 않습니다. 레이닝은 노트 / 자리 / 테두리 / 빛, 횟수는 자리 / 글자 / 움직임, 모양과 색은 색 / 모양 / 이미지로 나뉩니다.
- **캔버스 미리보기**: 모양과 색, 글자, 레이닝, 횟수 줄에 마우스를 잠깐 올리거나 그 페이지에 들어가 있으면, 캔버스의 그 키가 가끔씩 눌리며 그 부분이 하는 일을 직접 보여 줍니다. 레이닝이면 게임과 같은 자리에서 같은 모양으로 노트가 올라가고, 횟수면 숫자가 올라가고, 모양과 색이나 글자면 눌린 모습이 보입니다. 값을 바꾸면 다음 노트부터 바뀐 모습입니다. 편집 캔버스에서만 보이고 저장되거나 게임·오버레이로 가는 것은 없습니다. 고스트 키의 페이지에서는 보여 주지 않습니다.
- 요소의 페이지에는 제목이 없습니다. 무엇을 골랐는지는 캔버스에 보이기 때문입니다. 맨 위에는 목록으로 돌아가는 버튼과 **삭제**만 있습니다.
- **레이닝**, **횟수**, **소리**, **고스트 키**는 켜고 끌 수 있습니다. 줄 오른쪽에 **켬**/**끔**이 적혀 있고, 꺼진 줄도 다른 줄과 똑같이 눌러 들어갈 수 있습니다. 들어간 페이지 위쪽에 스위치가 있습니다. 꺼도 저장한 모양은 그대로 남고, 그 페이지의 설정은 자리를 지킨 채 흐려집니다.
- 색, 글꼴, 이미지, 소리 고르기는 다른 페이지로 넘어가지 않습니다. 누른 줄을 가리키는 **말풍선**이 사이드바 옆(캔버스 쪽)에 뜹니다. 사이드바의 줄은 가려지지도 움직이지도 않습니다. Esc나 바깥을 누르면 닫힙니다. 글꼴, 소리, 숫자 움직임처럼 목록에서 고르는 말풍선은 모두 같은 모양입니다: 검색 칸 하나, 종류는 한 줄의 버튼 묶음, 이름 줄(고른 것은 체크 표시, 글꼴은 그 글꼴로 쓰인 이름), 맨 아래 "글꼴 추가" 같은 추가 줄.
- 배경색, 테두리 색상, 글자 색, 횟수의 색처럼 **평소**와 **누를 때** 두 가지가 있는 색은 줄에 두 칸이 나란히 있습니다. 칸마다 지금 색과 이름이 보이고, 누른 칸의 색을 고릅니다. 말풍선 안에서 따로 전환하지 않습니다.
  - **누를 때** 색을 고르는 동안에는 캔버스에서 고른 키가 눌린 모습으로 보여, 고르는 색을 바로 확인할 수 있습니다.
  - 노브는 두 번째 칸의 이름이 **돌릴 때**입니다.
- **고스트 키**는 같은 자리에 다른 키보드 키를 연결하는 두 번째 얼굴입니다. 얼불춤 키 리미터에는 포함되지 않습니다.
- 다른 키를 골라도 보고 있던 페이지가 그대로 열려 있어, 같은 부분을 키마다 이어서 바꿀 수 있습니다.
- **누른 횟수**: 횟수 페이지 맨 아래 "누른 횟수" 판에 그 키의 지금 횟수가 있습니다. 키를 누르면 같이 올라가고, 숫자를 고치면 그 값이 됩니다(0이면 그 키만 초기화). 바꾼 것은 되돌리기(⌘Z)로 되돌릴 수 있습니다. 횟수 표시를 꺼도 이 판은 흐려지지 않습니다. 키보드 키가 연결된 키에만 있습니다.
- 페이지 위의 **삭제**로 요소를 지웁니다. Delete 키와 우클릭 메뉴로도 지울 수 있습니다.

여러 요소를 고르면 함께 바꿀 수 있는 부분만 나타나고, 바꾼 값은 고른 모든 요소에 적용됩니다. 키보드 키 연결은 하나씩 바꿉니다.

통계, 그래프, 노브도 같은 규칙입니다. 위치·크기처럼 값 몇 개인 것은 그 자리에서, 모양처럼 설정이 많은 것은 들어가서 고칩니다.

## 이미지 꾸미기

이미지는 키를 누르면 모습이 바뀌는 그림입니다. 다른 요소처럼 캔버스에서 고르고, 끌어 옮기고, 가장자리를 끌어 크기를 바꿉니다. 이미지를 아직 고르지 않은 것은 편집 화면에서만 점선 상자로 보입니다.

이미지의 페이지는 한 장입니다.

| 줄                     | 바꾸는 것                                                                         |
| ---------------------- | --------------------------------------------------------------------------------- |
| 이미지                 | 그림 고르기·지우기 (말풍선)                                                       |
| 위치, 크기, 회전, 표시 | 그 자리에서 고칩니다.                                                             |
| 평소 모습              | 키를 누르지 않을 때의 모습. 누르면 그 모습의 페이지                               |
| 모습 1, 모습 2 …       | 키를 누를 때의 모습. 줄에 어떤 키인지 보이고, 누르면 그 모습의 페이지             |
| 모습 추가              | 모습을 하나 더 만들고 바로 그 페이지를 엽니다.                                    |
| 키를 누르면            | **누르는 동안 유지** 또는 **잠깐 바뀌고 돌아옴**. 움직이는 그림으로 고릅니다.     |
| 움직임 느낌            | 부드럽게, 빠르게 출발, 천천히 출발, 일정하게, 통통 튀게 중에서 그림으로 고릅니다. |
| 바뀌는 시간            | 모습이 바뀌는 데 걸리는 시간 (슬라이더)                                           |
| 돌아오는 시간          | **잠깐 바뀌고 돌아옴**일 때 원래 모습으로 돌아오기까지의 시간                     |

모습의 페이지에서는 그 모습을 크게 보면서 고칩니다.

- 그림을 끌면 그만큼 옮겨집니다. 평소 모습이 뒤에 흐리게 보여 얼마나 달라지는지 알 수 있습니다.
- **눌러 보기**를 누르고 있으면 키를 누른 것처럼 캔버스의 이미지가 그 모습으로 바뀝니다. 아무것도 저장되지 않습니다.
- **누르는 키**에서 이 모습으로 바뀔 키를 고릅니다. 키를 아직 정하지 않은 모습은 **키 필요**로 표시되고, 키를 정하면 저장됩니다.
- 이름, 그림, 이동, 회전, 크기를 정합니다.
- **회전 중심**은 그림 위의 점을 눌러 정합니다. **평소 모습과 같은 중심**을 켜면 따로 정하지 않습니다.

## 캔버스 확대와 이동

- 트랙패드에서 두 손가락을 벌리거나 오므리면, 또는 ⌘(Windows는 Ctrl)를 누른 채 두 손가락으로 밀면 손가락이 움직인 만큼 확대·축소됩니다.
- 마우스 휠은 ⌘(Ctrl)를 누른 채 한 칸 돌릴 때마다 한 단계씩 바뀝니다.
- 두 손가락으로 밀거나 휠을 돌리면 캔버스가 움직입니다.

## 캔버스에서 맞추기

요소를 끌어 옮기거나 가장자리를 끌어 크기를 바꿀 때, 끄는 쪽이 아래 순서로 자리를 잡습니다. 옮기기, 크기 바꾸기, 여러 개를 함께 끌기 모두 같은 규칙입니다.

1. 화면에서 5픽셀 안에 다른 요소의 선(왼쪽·가운데·오른쪽, 위·중간·아래)이 있으면 가장 가까운 선에 맞춥니다. 같은 줄의 요소들과 간격이 같아지는 자리, 두 요소의 한가운데도 여기에 포함됩니다.
2. 가까운 선이 없으면 격자에 맞춥니다. 격자는 확대·축소와 상관없이 항상 같은 자리입니다.
3. 위치와 크기는 항상 정수입니다.

- 안내선은 실제로 맞았을 때만 나타납니다.
- 크기를 바꿀 때는 끄는 가장자리만 움직이고, 반대쪽은 그대로입니다. 다른 요소와 같은 크기가 되는 자리에도 맞춥니다.
- **Alt**를 누른 채 끌면 어디에도 맞추지 않습니다.
- **Shift**를 누른 채 옮기면 가로나 세로 한 방향으로만 움직입니다. 크기를 바꿀 때는 비율을 유지합니다.
- 방향키는 1씩, **Shift+방향키**는 격자 한 칸씩 옮깁니다.
- 격자 간격과 안내선 종류는 설정의 **편집 화면**에서 바꿉니다.

## 미니맵

캔버스 왼쪽 아래 미니맵을 끌면 보고 있는 범위가 끈 만큼 움직입니다. 누른 곳으로 바로 건너뛰지 않습니다.

## 설정

탭 줄 오른쪽의 **설정**을 누르면 설정 화면이 열리고, 제목 왼쪽의 화살표로 편집 화면에 돌아옵니다. 왼쪽 **설정 찾기**에 ‘소리’, ‘언어’처럼 짧은 말을 입력하면 해당 화면으로 갈 수 있습니다. 모든 키에 똑같이 적용되는 것은 여기에 있습니다.

| 화면        | 바꿀 수 있는 것                                                 |
| ----------- | --------------------------------------------------------------- |
| 보여 줄 곳  | 키뷰어를 보여 줄 세 곳과 각각의 설정 (아래 표)                  |
| 키뷰어 화면 | 배경색, 바깥 여백, 레이닝 (아래)                                |
| 편집 화면   | 격자 간격, 미니맵, 정렬·간격·크기 안내선                        |
| 키 소리     | 소리가 나올 스피커·헤드폰, ASIO 출력                            |
| 앱 사용     | 언어, 단축키, 창을 닫아도 계속 실행할지 선택                    |
| 기능 더하기 | 모양 파일(CSS), 추가 기능                                       |
| 고급 설정   | 화면 표시 방식, 레이닝 프레임 제한, 개발 도구, 키와 배치 초기화 |

레이닝과 누른 횟수는 설정 화면이 아니라 키마다 켜고 끕니다. 예전에 레이닝을 전체로 꺼 두었다면, 모든 키의 레이닝이 꺼진 상태로 옮겨집니다.

키뷰어를 파일로 저장하고 불러오는 것(프리셋)은 설정이 아니라 **키뷰어 고르기** 화면에 있습니다.

### 레이닝

**키뷰어 화면**에 레이닝의 값이 줄마다 하나씩 있습니다. 따로 여는 창은 없고, 값을 바꾸면 바로 저장됩니다. 숫자는 칸을 벗어나거나 Enter를 누를 때 적용됩니다.

| 줄                        | 하는 일                                                                               |
| ------------------------- | ------------------------------------------------------------------------------------- |
| 레이닝을 정할 키뷰어      | **모든 키뷰어**, 또는 키뷰어 하나를 골라 그 키뷰어만 따로 정합니다.                   |
| 레이닝 속도               | 레이닝이 1초에 흐르는 거리                                                            |
| 레이닝 길이               | 레이닝이 키에서부터 흘러가는 거리                                                     |
| 아래로 흐르기             | 켜면 키 아래쪽으로, 끄면 위쪽으로 흐릅니다.                                           |
| 끝부분 흐리게             | 위쪽 끝과 아래쪽 끝에서 서서히 사라지는 길이                                          |
| 짧은 레이닝 길이 일정하게 | 아주 짧게 누른 키도 정해 둔 길이로 보여 줍니다.                                       |
| 짧은 레이닝 길이          | 위 스위치가 켜져 있을 때, 짧게 누른 키의 레이닝 길이                                  |
| 짧게 눌렀다고 볼 시간     | 위 스위치가 켜져 있을 때, 이보다 짧게 누르면 짧은 레이닝                              |
| 키 표시 늦추기            | 키가 눌린 표시를 늦춥니다. **추천 값 쓰기**로 레이닝이 끝까지 흐르는 시간에 맞춥니다. |

- 키뷰어 하나를 골라 값을 바꾸면 그 키뷰어만 따로 정해지고, 목록에 **(따로 정함)** 이라고 표시됩니다. **모든 키뷰어와 같게**를 누르면 따로 정한 값이 지워집니다.
- 레이닝을 1초에 몇 번까지 그릴지(프레임 제한)는 컴퓨터 성능에 관한 것이어서 **고급 설정**에 있습니다.

### 보여 줄 곳

설정을 열면 맨 먼저 나오는 화면입니다. 키뷰어를 보여 줄 곳은 세 곳이고, **한 번에 한 곳만** 씁니다. 맨 위의 큰 버튼 셋 중 하나를 누르면 그곳이 선택되고, 선택된 곳의 버튼만 그림이 움직입니다. 버튼 아래에는 선택한 곳의 설정만 나옵니다.

| 곳                        | 버튼의 그림                               | 선택하면 아래에 나오는 것                                 |
| ------------------------- | ----------------------------------------- | --------------------------------------------------------- |
| 얼불춤 안                 | 창 안에 든 키뷰어가 창과 함께 움직임      | (따로 정할 것 없음)                                       |
| 바탕화면 위               | 움직이는 창 위에 떠 있는 키뷰어           | 위치 고정, 다른 창 위에 표시, 기준점                      |
| OBS 방송 화면 (부가 기능) | 살짝 튀어 오르는 OBS 표시와 눌리는 키뷰어 | 브라우저 소스 주소 복사, 새 주소, 연결된 브라우저 소스 수 |

- 처음에는 **얼불춤 안**이 선택되어 있습니다.
- 얼불춤 연결 상태, **키 리미터**, 게임에 적용된 키는 어느 곳을 고르든 항상 아래에 있습니다.
- 창이 좁아지면 버튼 안의 그림이 작아집니다.
- **바탕화면 위**는 단축키 Ctrl+Shift+O(macOS는 ⌘+Shift+O)로도 켜고 끕니다.
- **새 주소**를 만들면 지금 주소는 더 쓸 수 없습니다. 게임 안 키뷰어는 새 주소를 스스로 받아 다시 뜹니다.

## 확인 창

지우기나 초기화처럼 묻고 진행하는 창은 답이 항상 같은 자리에 같은 크기로 있습니다. 왼쪽이 **취소**, 오른쪽이 진행입니다.

- 되돌릴 수 없는 일(삭제, 초기화, 새 주소)은 진행 버튼이 빨간색이고, 창이 열리면 **취소**가 먼저 선택되어 있습니다. Enter를 눌러도 아무 일도 일어나지 않습니다.
- 그 밖의 질문은 진행 버튼이 먼저 선택되어 있어 Enter로 진행합니다.
- Esc나 창 바깥을 누르면 취소입니다.

## 창 크기 바꾸기

창의 가장자리나 모서리를 끌어 넓이와 높이를 바꿀 수 있습니다. Windows에서는 맨 위 줄 오른쪽에 앱이 직접 그린 최소화·최대화·닫기 버튼이 있습니다. macOS에서는 기본 창 버튼을 사용합니다.

일반 창의 위치와 크기는 창을 닫거나 앱을 종료할 때 기억합니다. 다음에 열면 그 위치와 크기로 돌아오며, 모니터가 바뀌면 현재 화면 안에 들어오도록 맞춥니다. 최대화하거나 최소화해도 원래 창 크기를 덮어쓰지 않습니다.
