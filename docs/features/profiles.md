# 프로필

설정을 여러 묶음으로 저장해 두고 바꿔 쓰거나, 파일로 내보내 다른 PC나 다른
사람과 나눕니다. **일반 → 프로필**에서 관리합니다.

## 프로필에 담기는 것

| 프로필마다 따로 | 모든 프로필이 함께 씀 |
| --- | --- |
| 오버레이 요소와 배치 | 채터 블로커 (키보드마다 맞추는 값) |
| 이펙트 프리셋과 적용 중인 프리셋, 프리셋 단축키 | 설정 단축키, 움직임 줄이기 |
| Tweaks: 에디터 도구, 판정 표시, 행성 꾸미기 | ElementNote 자동 열기, 자동 업데이트 |
| 하이라이트 색, 오버레이 기본 폰트 | 녹화 모드, macOS 트랙패드, 자동 맞춤 |
| ElementNote 키뷰어 전체: 손·발의 모든 키뷰어와 그 설정 (ElementNote **전체 저장**에 담기는 것), 키별 누른 횟수 | ElementNote 앱 설정: 언어, 보여 줄 곳, 단축키, 소리 출력 |

## 쓰는 법

- **전환**: 프로필 카드를 누르면 바로 바뀝니다. 그 전에 쓰던 값은 원래
  프로필에 남습니다. 이펙트 변경은 레벨을 시작하거나 재시작할 때 반영됩니다.
  ElementNote 키뷰어는 잠시 뒤 그 프로필의 것으로 바뀝니다. ElementNote가 꺼져
  있으면 다음에 켜질 때 바뀝니다. 전환 전의 ElementNote 실행 취소 기록은 지워집니다.
- **새 프로필**: 버튼 아래 작은 창에 이름을 넣고 만들기(또는 Enter)를 누르면
  처음 설치했을 때의 설정으로 새 프로필을 만들고 바로 사용합니다. ElementNote
  키뷰어도 처음 설치했을 때의 키뷰어로 시작합니다. 채터 블로커처럼 모든 프로필이
  함께 쓰는 값은 그대로입니다.
- **복제**: 카드의 복제 버튼을 누르면 그 프로필의 값과 키뷰어를 그대로 담은
  "이름 복사본"을 카드 바로 뒤에 만듭니다. 쓰던 프로필은 바뀌지 않습니다.
- **가져오기**: `.eprofile` 파일(예전의 `.elementprofile`도)을 고르면 새 프로필로 추가하고 그
  프로필로 바꿉니다. 파일에 키뷰어가 있으면 ElementNote도 그 키뷰어로 바뀌고, 없으면
  지금 보이는 키뷰어로 시작합니다. 이름이 겹치면 뒤에 숫자가 붙습니다. 기존 프로필은 그대로
  남습니다. 가져온 프로필이 이 PC에 없는 폰트를 쓰면 바로 그 폰트 목록을 보여 주고,
  폰트마다 대신 쓸 폰트를 고를 수 있습니다. 고른 폰트는 원래 폰트가 쓰이던
  자리에만 들어갑니다. 고르지 않으면 설치하거나 추가할 때까지 기본 폰트로 보입니다.
- **이름 바꾸기**: 카드의 연필 버튼을 누르면 카드의 이름이 입력칸으로 바뀝니다.
  Enter나 다른 곳을 누르면 저장하고, Esc는 취소합니다. 쓸 수 없는 이름이면
  원래 이름을 두고 이유를 알려 줍니다.
- **내보내기**: 카드의 내보내기 버튼을 누르면 바로 저장 창이 열립니다. 프로필
  이름이 파일 이름으로 제안됩니다. 키뷰어(이미지·사운드·폰트 포함)도 같이 담깁니다.
  누른 횟수는 이 PC의 기록이라 담지 않습니다.
  사용 중인 프로필을 ElementNote가 꺼진 채 내보내면 키뷰어는 빠지고, 카드 아래에
  ElementNote를 켜고 다시 내보내라는 안내가 나옵니다.
- **삭제**: 카드의 휴지통을 누르면 카드에 "한 번 더 누르면 삭제해요"가 뜨고, 한
  번 더 누르면 지웁니다. 사용 중인 프로필을 지우면 옆 프로필로 먼저 바뀝니다.
  마지막 하나는 지울 수 없습니다.
- 결과와 문제 안내는 카드 아래에 나와서 카드 위치가 움직이지 않습니다. 전환은
  카드의 "사용 중" 표시로 보여 줍니다.

## 백업

가져오기와 삭제 직전에 모든 프로필을 포함한 설정 전체를 모드 폴더의
`Backups/Settings-<날짜-시각>.xml`로 복사합니다. 최근 10개만 남깁니다. 되돌리려면
게임을 끈 뒤 원하는 백업을 `Settings.xml`로 바꿔 넣습니다.

삭제한 프로필의 키뷰어는 `Backups/KeyViewers-<날짜-시각>.json`으로 옮깁니다(최근
10개). ElementNote의 **전체 불러오기**로 바로 열 수 있습니다.

## 파일 형식

`.eprofile`은 UTF-8 XML입니다. 예전에 내보낸 `.elementprofile`도 같은
형식이라 그대로 가져옵니다. 루트는 `ElementProfile`이고 `Format`(파일
형식 버전), `ModVersion`(만든 Element 버전), `Name`, `Content`(프로필 값과 그 값의
`SettingsVersion`), `KeyViewers`(ElementNote **전체 저장** 파일 내용 그대로인 JSON,
없으면 생략)를 담습니다. `KeyViewers`를 모르는 예전 Element는 이 칸을 건너뛰고
나머지를 가져옵니다.

- 가져올 때 `Content`를 `Settings.xml`과 같은 마이그레이션에 통과시키므로 예전
  버전에서 내보낸 파일도 그대로 가져옵니다.
- 더 새 `Format`이나 `SettingsVersion`은 거절하고, 만든 버전을 알려 Element
  업데이트를 안내합니다.
- DTD와 외부 참조는 읽지 않습니다. 키뷰어 이미지가 들어가므로 64MB를 넘는 파일만
  열지 않습니다.

## 구현 메모

- 사용 중인 프로필의 값은 `Settings.xml`의 원래 자리에 있고, 나머지 프로필은
  `Profiles` 목록에 `Content`로 저장됩니다. 사용 중인 프로필의 `Content`는 비어
  있습니다.
- 전환은 새 설정 객체를 만들지 않고 기존 객체 안의 값을 바꿉니다
  (`SettingsCopy`). 설정 창, 캔버스, Tweaks가 잡고 있는 참조가 그대로 유효합니다.
  새 필드를 추가하면 저장되는 필드는 자동으로 프로필에 따라갑니다.
- 프로필에 들어갈지 정해야 하는 새 설정은 `ProfileContent`에 필드를 추가하고
  `Capture`·`Apply`에서 다룹니다.
- 키뷰어는 ElementNote가 갖고 있습니다. ElementNote는 한 프로필의 키뷰어만 화면에
  두고, 그게 어느 프로필 것인지 `store.json`의 `keyViewersOwner`에 키뷰어와 같은
  저장으로 기록합니다. 나머지 프로필의 키뷰어는 모드 폴더 `Profiles/<프로필 id>.json`
  (전체 저장 형식)에 있습니다. 화면에 있는 프로필의 파일은 없습니다.
- 사용 중인 프로필과 ElementNote 화면의 주인이 다르면 `ProfileKeyViewers`가
  ElementNote에 `key-viewers.swap`을 보냅니다. ElementNote는 화면의 키뷰어를 주인의
  파일에 저장하고, 새 프로필의 파일(또는 처음 설치 키뷰어, 또는 그대로)을 불러와
  주인을 바꿉니다. 요청에 게임이 알고 있는 주인(`expected`)이 들어가고, 다르면
  ElementNote가 거절하고 실제 주인을 알려 줍니다. 응답이 늦어 게임이 포기한 교체가
  나중에 끝나도 다른 프로필의 키뷰어를 엉뚱한 파일에 저장하지 않습니다.
- 교체 때 저장하는 파일에는 그 프로필의 누른 횟수(`keyCounters`)도 들어가고, 다시
  불러올 때 같은 커밋으로 되돌립니다. 전체 저장·내보내기에는 넣지 않고, Element가
  내보낼 때 대기 파일에서 빼냅니다.
- 키뷰어 데이터는 IPC 메시지 한도(1MiB)를 넘을 수 있어서 파일 경로로만 주고받습니다.
  ElementNote 쪽은 `commands/preset/profile.rs`(전체 저장·불러오기와 같은 코드,
  불러오기는 실행 취소 기록을 남기지 않고 폰트 목록을 합침)와
  `ipc/profileKeyViewersIpcCoordinator.ts`입니다.
- 이 기능 전부터 있던 프로필은 처음 쓸 때 화면의 키뷰어를 이어받습니다(`KeyViewersStart`).
  새 프로필은 처음 설치 키뷰어, ElementNote가 없을 때 만든 복제본은 원본의 키뷰어로
  시작합니다.
- 파일 창은 macOS가 `native/macos/FileDialog.mm`(NSOpenPanel·NSSavePanel,
  `native/libElementFileDialog.dylib`), Windows가 comdlg32입니다. 둘 다 게임의
  메인 스레드에서 모달로 열리고, 고르거나 닫을 때까지 게임 화면이 멈춥니다.
  Linux는 파일 창이 없어 가져오기·내보내기 버튼을 숨깁니다.
