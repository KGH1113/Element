# 프로필

설정을 여러 묶음으로 저장해 두고 바꿔 쓰거나, 파일로 내보내 다른 PC나 다른
사람과 나눕니다. **일반 → 프로필**에서 관리합니다.

## 프로필에 담기는 것

| 프로필마다 따로 | 모든 프로필이 함께 씀 |
| --- | --- |
| 오버레이 요소와 배치 | 채터 블로커 (키보드마다 맞추는 값) |
| 이펙트 프리셋과 적용 중인 프리셋, 프리셋 단축키 | 설정 단축키, 움직임 줄이기 |
| Tweaks: 에디터 도구, 판정 표시, 행성 꾸미기 | ElementNote 자동 열기, 자동 업데이트 |
| 하이라이트 색, 오버레이 기본 폰트 | 녹화 모드, macOS 트랙패드, 자동 맞춤 |

## 쓰는 법

- **전환**: 프로필 카드를 누르면 바로 바뀝니다. 그 전에 쓰던 값은 원래
  프로필에 남습니다. 이펙트 변경은 레벨을 시작하거나 재시작할 때 반영됩니다.
- **새 프로필**: 버튼 아래 작은 창에 이름을 넣고 만들기(또는 Enter)를 누르면
  처음 설치했을 때의 설정으로 새 프로필을 만들고 바로 사용합니다. 채터 블로커처럼
  모든 프로필이 함께 쓰는 값은 그대로입니다.
- **복제**: 카드의 복제 버튼을 누르면 그 프로필의 값을 그대로 담은 "이름 복사본"을
  카드 바로 뒤에 만듭니다. 쓰던 프로필은 바뀌지 않습니다.
- **가져오기**: `.eprofile` 파일(예전의 `.elementprofile`도)을 고르면 새 프로필로 추가하고 그
  프로필로 바꿉니다. 이름이 겹치면 뒤에 숫자가 붙습니다. 기존 프로필은 그대로
  남습니다. 가져온 프로필이 이 PC에 없는 폰트를 쓰면 바로 그 폰트 목록을 보여 주고,
  폰트마다 대신 쓸 폰트를 고를 수 있습니다. 고른 폰트는 원래 폰트가 쓰이던
  자리에만 들어갑니다. 고르지 않으면 설치하거나 추가할 때까지 기본 폰트로 보입니다.
- **이름 바꾸기**: 카드의 연필 버튼을 누르면 카드의 이름이 입력칸으로 바뀝니다.
  Enter나 다른 곳을 누르면 저장하고, Esc는 취소합니다. 쓸 수 없는 이름이면
  원래 이름을 두고 이유를 알려 줍니다.
- **내보내기**: 카드의 내보내기 버튼을 누르면 바로 저장 창이 열립니다. 프로필
  이름이 파일 이름으로 제안됩니다.
- **삭제**: 카드의 휴지통을 누르면 카드에 "한 번 더 누르면 삭제해요"가 뜨고, 한
  번 더 누르면 지웁니다. 사용 중인 프로필을 지우면 옆 프로필로 먼저 바뀝니다.
  마지막 하나는 지울 수 없습니다.
- 결과와 문제 안내는 카드 아래에 나와서 카드 위치가 움직이지 않습니다. 전환은
  카드의 "사용 중" 표시로 보여 줍니다.

## 백업

가져오기와 삭제 직전에 모든 프로필을 포함한 설정 전체를 모드 폴더의
`Backups/Settings-<날짜-시각>.xml`로 복사합니다. 최근 10개만 남깁니다. 되돌리려면
게임을 끈 뒤 원하는 백업을 `Settings.xml`로 바꿔 넣습니다.

## 파일 형식

`.eprofile`은 UTF-8 XML입니다. 예전에 내보낸 `.elementprofile`도 같은
형식이라 그대로 가져옵니다. 루트는 `ElementProfile`이고 `Format`(파일
형식 버전), `ModVersion`(만든 Element 버전), `Name`, `Content`(프로필 값과 그 값의
`SettingsVersion`)를 담습니다.

- 가져올 때 `Content`를 `Settings.xml`과 같은 마이그레이션에 통과시키므로 예전
  버전에서 내보낸 파일도 그대로 가져옵니다.
- 더 새 `Format`이나 `SettingsVersion`은 거절하고, 만든 버전을 알려 Element
  업데이트를 안내합니다.
- DTD와 외부 참조는 읽지 않습니다. 16MB를 넘는 파일은 열지 않습니다.

## 구현 메모

- 사용 중인 프로필의 값은 `Settings.xml`의 원래 자리에 있고, 나머지 프로필은
  `Profiles` 목록에 `Content`로 저장됩니다. 사용 중인 프로필의 `Content`는 비어
  있습니다.
- 전환은 새 설정 객체를 만들지 않고 기존 객체 안의 값을 바꿉니다
  (`SettingsCopy`). 설정 창, 캔버스, Tweaks가 잡고 있는 참조가 그대로 유효합니다.
  새 필드를 추가하면 저장되는 필드는 자동으로 프로필에 따라갑니다.
- 프로필에 들어갈지 정해야 하는 새 설정은 `ProfileContent`에 필드를 추가하고
  `Capture`·`Apply`에서 다룹니다.
- 파일 창은 macOS가 `native/macos/FileDialog.mm`(NSOpenPanel·NSSavePanel,
  `native/libElementFileDialog.dylib`), Windows가 comdlg32입니다. 둘 다 게임의
  메인 스레드에서 모달로 열리고, 고르거나 닫을 때까지 게임 화면이 멈춥니다.
  Linux는 파일 창이 없어 가져오기·내보내기 버튼을 숨깁니다.
