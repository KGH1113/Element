ImplResourcePack의 첫 배포 버전입니다. 이 버전부터는 게임을 켤 때 새 버전이 자동으로 설치됩니다.

## 설치

**필요한 것:** A Dance of Fire and Ice · UnityModManager 0.27 이상 · Harmony

1. 아래 **Assets**에서 운영체제에 맞는 파일을 받습니다.
   - macOS: `ImplResourcePack-macos.zip`
   - Windows: `ImplResourcePack-windows.zip`
2. 압축을 풀어 나온 `ImplResourcePack` 폴더를 얼불춤의 `Mods` 폴더에 넣습니다. Windows는 UnityModManager의 **Mods** 탭에 zip을 끌어다 놓아도 됩니다.
3. 게임에서 **왼쪽 Alt + Tab**(macOS는 **⌥ + Tab**)을 누르면 설정이 열립니다.

소스에서 빌드해 쓰던 설치 위에 덮어도 설정은 그대로 남습니다.

macOS에서 라이브러리를 열 수 없다는 경고가 나오면, 다운로드한 파일에 붙은 격리 표시를 지우고 게임을 다시 켭니다.

```bash
xattr -dr com.apple.quarantine ~/"Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods/ImplResourcePack"
```

## 새로운 점

- **자동 업데이트**: 게임을 켤 때 새 버전을 받아 그 실행에서 바로 적용합니다. 함께 들어 있는 ImplDmNote도 같이 업데이트됩니다. 설정 → 일반 → **자동 업데이트**에서 끌 수 있습니다.
- **ImplDmNote 포함**: 게임을 켜면 ImplDmNote도 함께 열리고, 게임을 끄면 닫힙니다. 설정 → 일반 → **ImplDmNote 자동 열기/닫기**에서 끌 수 있습니다.
- **게임 내 키뷰어 크기**: 100%일 때 ImplDmNote 창과 같은 크기로 보입니다. 전에 키뷰어를 크게 키워 두었다면 100%로 되돌려 주세요.
- **키 리미터 표시**: ImplDmNote 키가 적용 중이면 게임 설정의 Key Limiter 줄에 "ImplDmNote 키"가 표시됩니다.
- ImplDmNote가 꺼져 있으면 오버레이 편집기에 키뷰어 카드와 틀이 나오지 않습니다. 앱이 연결되면 바로 나타납니다.
