## English

The first release of **ImplResourcePack**, an overlay and quality-of-life mod for A Dance of Fire and Ice.

- **Overlay**: progress, accuracy, music/map time, BPM, KPS, FPS, judgments, combo and more. Drag them anywhere and resize them; the layout keeps up with resolution changes.
- **In-game key viewer**: shows the hand and foot key viewers of ImplDmNote, the key viewer app that comes with the mod, inside the game screen. At 100% it is the same size as the ImplDmNote window.
- **ImplDmNote included**: opens and closes with the game.
- **Effect Remover** presets, **Tweaks** (planet colors, editor tools, hiding judgment text, a chatter blocker), a recording mode, and a Korean and English UI.
- **Automatic updates**: from this version on, the mod installs new versions by itself when the game starts.

### Which file do I download?

| Your computer | Download |
| --- | --- |
| Windows 10 or later | `ImplResourcePack-windows.zip` |
| macOS 11 or later | `ImplResourcePack-macos.zip` |

On Intel Macs the mod runs, but the bundled ImplDmNote, and with it the in-game key viewer, needs Apple silicon for now.

You need only one of them. `ImplResourcePack.update.json` is read by the mod's updater, and the "Source code" archives are for developers; you don't need either.

### Install

**You need:** A Dance of Fire and Ice with [UnityModManager](https://github.com/newman55/unity-mod-manager) 0.27 or later. On Windows, the in-game key viewer also needs the Microsoft Edge WebView2 Runtime (Windows 11 has it).

1. Download the zip for your computer from **Assets** below.
2. Unzip it and move the `ImplResourcePack` folder into the game's `Mods` folder. In Steam, right-click the game → **Manage** → **Browse local files** to find it.
   - Windows: `...\steamapps\common\A Dance of Fire and Ice\Mods`. You can also drag the zip onto the **Mods** tab of UnityModManager.
   - macOS: `~/Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods`
3. Start the game and press **Left Alt + Tab** (**⌥ + Tab** on macOS) to open the settings.

If macOS says a library from the mod can't be opened, remove the download mark from the folder and start the game again:

```bash
xattr -dr com.apple.quarantine ~/"Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods/ImplResourcePack"
```

### Updates

When you start the game, the mod checks for a new version and applies it in the same launch, ImplDmNote included. Turn it off in Settings → General → **Automatic updates**.

Built it from source before? Install over it; your settings stay. Key viewers you enlarged will now look bigger, so set them back to 100%.

## 한국어

얼불춤(A Dance of Fire and Ice) 오버레이·편의 기능 모드 **ImplResourcePack**의 첫 배포 버전입니다.

- **오버레이**: 진행도·정확도·음악/맵 시간·BPM·KPS·FPS·판정·콤보 등을 원하는 자리에 놓고 크기를 바꿉니다. 해상도가 바뀌어도 배치가 유지됩니다.
- **게임 내 키뷰어**: 모드와 함께 들어 있는 키뷰어 앱 ImplDmNote의 손·발 키뷰어를 게임 화면 안에 띄웁니다. 100%일 때 ImplDmNote 창과 같은 크기입니다.
- **ImplDmNote 포함**: 게임과 함께 열리고 닫힙니다.
- **Effect Remover** 프리셋, **Tweaks**(행성 꾸미기, 에디터 도구, 판정 문구 숨김, 채터 블로커), 녹화 모드, 한국어·영어 UI.
- **자동 업데이트**: 이 버전부터 게임을 켤 때 새 버전이 자동으로 설치됩니다.

### 어떤 파일을 받나요?

| 내 컴퓨터 | 받을 파일 |
| --- | --- |
| Windows 10 이상 | `ImplResourcePack-windows.zip` |
| macOS 11 이상 | `ImplResourcePack-macos.zip` |

Intel Mac에서도 모드는 동작하지만, 함께 들어 있는 ImplDmNote와 그것을 쓰는 게임 내 키뷰어는 아직 Apple 실리콘에서만 실행됩니다.

둘 중 하나만 받으면 됩니다. `ImplResourcePack.update.json`은 모드의 업데이터가 읽는 파일이고, "Source code" 압축 파일은 개발용이라 받지 않아도 됩니다.

### 설치

**필요한 것:** [UnityModManager](https://github.com/newman55/unity-mod-manager) 0.27 이상을 설치한 얼불춤. Windows에서 게임 내 키뷰어를 쓰려면 Microsoft Edge WebView2 런타임도 필요합니다(Windows 11에는 기본으로 있습니다).

1. 아래 **Assets**에서 내 컴퓨터에 맞는 zip을 받습니다.
2. 압축을 풀어 나온 `ImplResourcePack` 폴더를 얼불춤의 `Mods` 폴더에 넣습니다. Steam에서 게임을 오른쪽 클릭 → **관리** → **로컬 파일 보기**로 게임 폴더를 열 수 있습니다.
   - Windows: `...\steamapps\common\A Dance of Fire and Ice\Mods`. UnityModManager의 **Mods** 탭에 zip을 끌어다 놓아도 됩니다.
   - macOS: `~/Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods`
3. 게임을 켜고 **왼쪽 Alt + Tab**(macOS는 **⌥ + Tab**)을 누르면 설정이 열립니다.

macOS에서 모드의 라이브러리를 열 수 없다는 경고가 나오면, 다운로드 표시를 지우고 게임을 다시 켭니다.

```bash
xattr -dr com.apple.quarantine ~/"Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods/ImplResourcePack"
```

### 업데이트

게임을 켤 때 새 버전이 있는지 확인하고 그 실행에서 바로 적용합니다. ImplDmNote도 함께 업데이트됩니다. 설정 → 일반 → **자동 업데이트**에서 끌 수 있습니다.

전에 소스에서 빌드해 쓰고 있었다면 그 위에 덮어 설치하세요. 설정은 그대로 남습니다. 키뷰어를 키워 두었다면 이제 더 크게 보이니 100%로 되돌려 주세요.
