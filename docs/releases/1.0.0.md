## English

### What's new

- **New name**: ImplResourcePack is now **Element**, and ImplDmNote is now **ElementNote**.
- **Judgment text follows ADOFAI**: while Competitive Mode is on, the popups you hide in Tweaks → **Judgment visuals** and ADOFAI's own **Hide Judgment Text** change together. Pick a step in the game's pause menu and Element hides exactly that. Hide more in Element, like Miss on its own, and Element hides the extra ones itself. Multipress now hides with Perfect, as it does in the game.
- **Ready to go**: ElementNote starts with note effects and OBS mode on, so in-game key viewers show without a trip to its settings. The chatter blocker also starts on.

### Coming from ImplResourcePack 0.5.0 or earlier

Because of the new name, your old install won't update to Element by itself.

1. Install Element as described below.
2. To keep your attempt counts, copy `Attempts.dat` from the old `ImplResourcePack` folder into the new `Element` folder.
3. Delete the old `ImplResourcePack` folder so the two mods don't run together.

Element and ElementNote start with new settings, so set up your overlay and key viewers again. From 1.0.0 on, updates install by themselves again. Turn this off in Settings → General → **Automatic updates**.

### Which file do I download?

| Your computer | Download |
| --- | --- |
| Windows 10 or later | `Element-windows.zip` |
| macOS 11 or later | `Element-macos.zip` |

On Intel Macs the mod runs, but the bundled ElementNote, and with it the in-game key viewer, needs Apple silicon for now.

You need only one of them. `Element.update.json` is read by the mod's updater, and the "Source code" archives are for developers; you don't need either.

### Install

**You need:** A Dance of Fire and Ice with [UnityModManager](https://github.com/newman55/unity-mod-manager) 0.27 or later. On Windows, the in-game key viewer also needs the Microsoft Edge WebView2 Runtime (Windows 11 has it).

1. Download the zip for your computer from **Assets** below.
2. Unzip it and move the `Element` folder into the game's `Mods` folder. In Steam, right-click the game → **Manage** → **Browse local files** to find it.
   - Windows: `...\steamapps\common\A Dance of Fire and Ice\Mods`. You can also drag the zip onto the **Mods** tab of UnityModManager.
   - macOS: `~/Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods`
3. Start the game and press **Left Alt + Tab** (**⌥ + Tab** on macOS) to open the settings.

If macOS says a library from the mod can't be opened, remove the download mark from the folder and start the game again:

```bash
xattr -dr com.apple.quarantine ~/"Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods/Element"
```

## 한국어

### 바뀐 점

- **새 이름**: ImplResourcePack은 이제 **Element**, ImplDmNote는 **ElementNote**입니다.
- **얼불춤과 함께 바뀌는 판정 문구 숨김**: 경쟁 모드가 켜져 있으면 Tweaks → **판정 표시**에서 숨긴 판정과 얼불춤의 **판정 텍스트 숨기기**가 함께 바뀝니다. 게임의 일시정지 메뉴에서 단계를 고르면 Element도 그대로 숨깁니다. Miss만 숨기는 것처럼 Element에서 더 숨긴 판정은 Element가 따로 숨깁니다. 다중입력은 게임처럼 Perfect와 함께 숨겨집니다.
- **바로 쓸 수 있는 기본값**: ElementNote는 노트 효과와 OBS 모드가 켜진 채로 시작해서, 설정을 열지 않아도 게임 내 키뷰어가 보입니다. 채터 블로커도 켜진 채로 시작합니다.

### ImplResourcePack 0.5.0 이하에서 넘어온다면

이름이 바뀌어서 기존 설치는 Element로 자동 업데이트되지 않습니다.

1. 아래 설명대로 Element를 설치합니다.
2. 시도 횟수를 이어가려면 기존 `ImplResourcePack` 폴더의 `Attempts.dat`를 새 `Element` 폴더로 복사합니다.
3. 두 모드가 함께 실행되지 않도록 기존 `ImplResourcePack` 폴더를 지웁니다.

Element와 ElementNote는 새 설정으로 시작하니 오버레이와 키뷰어를 다시 맞춰 주세요. 1.0.0부터는 다시 게임을 켤 때 자동으로 업데이트됩니다. 설정 → 일반 → **자동 업데이트**에서 끌 수 있습니다.

### 어떤 파일을 받나요?

| 내 컴퓨터 | 받을 파일 |
| --- | --- |
| Windows 10 이상 | `Element-windows.zip` |
| macOS 11 이상 | `Element-macos.zip` |

Intel Mac에서도 모드는 동작하지만, 함께 들어 있는 ElementNote와 그것을 쓰는 게임 내 키뷰어는 아직 Apple 실리콘에서만 실행됩니다.

둘 중 하나만 받으면 됩니다. `Element.update.json`은 모드의 업데이터가 읽는 파일이고, "Source code" 압축 파일은 개발용이라 받지 않아도 됩니다.

### 설치

**필요한 것:** [UnityModManager](https://github.com/newman55/unity-mod-manager) 0.27 이상을 설치한 얼불춤. Windows에서 게임 내 키뷰어를 쓰려면 Microsoft Edge WebView2 런타임도 필요합니다(Windows 11에는 기본으로 있습니다).

1. 아래 **Assets**에서 내 컴퓨터에 맞는 zip을 받습니다.
2. 압축을 풀어 나온 `Element` 폴더를 얼불춤의 `Mods` 폴더에 넣습니다. Steam에서 게임을 오른쪽 클릭 → **관리** → **로컬 파일 보기**로 게임 폴더를 열 수 있습니다.
   - Windows: `...\steamapps\common\A Dance of Fire and Ice\Mods`. UnityModManager의 **Mods** 탭에 zip을 끌어다 놓아도 됩니다.
   - macOS: `~/Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods`
3. 게임을 켜고 **왼쪽 Alt + Tab**(macOS는 **⌥ + Tab**)을 누르면 설정이 열립니다.

macOS에서 모드의 라이브러리를 열 수 없다는 경고가 나오면, 다운로드 표시를 지우고 게임을 다시 켭니다.

```bash
xattr -dr com.apple.quarantine ~/"Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods/Element"
```
