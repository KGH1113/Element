## English

### What's new

- **Build your own overlay**: Overlay → **Add Element** now offers **Text**, **Key viewer** and **Shape**.
  - **Text** mixes your own words with live values: progress (also start and current on their own), X-Accuracy, each judgment and the whole judgment row, combo, timing scale, time, tile and current BPM, keys per second, song title, attempts and FPS. Type `FPS | `, add the FPS value, and the overlay shows `FPS | 240`.
  - The text editor dims the game and shows your text at its real size. Values sit at the bottom by category and act like one character. Select characters to change their size in pixels or their color.
  - **Shapes** are squares, triangles and circles drawn behind your text. Drag a corner to reshape it, the small dot inside a corner to round it, and the dashed box to resize. Click a handle without dragging to type exact values. Each shape has its own fill and border.
  - Every color either follows the highlight color, keeping its own opacity, or is a color you pick.
- **A toolbar for each element**: selecting an element opens a second toolbar with its own controls: text size, hand or foot key viewer, shape kind, fill and border. Drag it by its grip; it stays where you put it.
- **Your overlay comes along**: the overlays you already placed turn into texts with the same values, colors and places. Progress, accuracy and BPM now use the highlight color directly instead of fading toward it. The combo becomes two texts, "Perfect" and the number.
- **ElementNote opens on its own**: the game installs it in Applications on macOS (Launchpad, Spotlight) and adds a Start menu shortcut on Windows, so you can open it without ADOFAI.
- **Fixes**: toolbars over an in-game key viewer keep their rounded corners, and the caret shows in number fields like the size percentage.

### Updating

From 1.0.0, the game updates itself the next time you start it. From ImplResourcePack 0.5.0 or earlier, follow [the 1.0.0 notes](https://github.com/KGH1113/Element/releases/tag/v1.0.0) first.

### Which file do I download?

| Your computer | Download |
| --- | --- |
| Windows 10 or later | `Element-windows.zip` |
| macOS 11 or later | `Element-macos.zip` |

On Intel Macs the mod runs, but the bundled ElementNote, and with it the in-game key viewer, needs Apple silicon for now.

You need only one of them. `Element.update.json` is read by the mod's updater, and the "Source code" archives are for developers; you don't need either.

### Install

**You need:** A Dance of Fire and Ice with [UnityModManager](https://github.com/newman55/unity-mod-manager) 0.27 or later. On Windows, the in-game key viewer also needs the Microsoft Edge WebView2 Runtime (Windows 11 has it).

1. Download the zip for your computer from **Assets** below.
2. Unzip it and move the `Element` folder into the game's `Mods` folder. In Steam, right-click the game → **Manage** → **Browse local files** to find it.
   - Windows: `...\steamapps\common\A Dance of Fire and Ice\Mods`. You can also drag the zip onto the **Mods** tab of UnityModManager.
   - macOS: `~/Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods`
3. Start the game and press **Left Alt + Tab** (**⌥ + Tab** on macOS) to open the settings.

If macOS says a library from the mod can't be opened, remove the download mark from the folder and start the game again:

```bash
xattr -dr com.apple.quarantine ~/"Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods/Element"
```

## 한국어

### 바뀐 점

- **직접 만드는 오버레이**: 오버레이 → **요소 추가**에서 **텍스트**, **키뷰어**, **도형**을 고릅니다.
  - **텍스트**는 입력한 글자에 실시간 값을 섞습니다. 진행도(시작 지점과 현재 진행도도 따로), 절대 정확도, 판정별 개수와 판정 한 줄, 콤보, 타이밍 배율, 시간, 타일·현재 BPM, 초당 입력 수, 곡 제목, 시도 횟수, FPS를 넣을 수 있습니다. `FPS | `를 입력하고 FPS 값을 넣으면 `FPS | 240`처럼 보입니다.
  - 텍스트 편집 화면은 게임을 어둡게 하고 텍스트를 실제 크기로 보여 줍니다. 값은 아래에 카테고리별로 있고 한 글자처럼 다뤄집니다. 글자를 선택하면 크기(px)와 색을 바꿀 수 있습니다.
  - **도형**은 텍스트 뒤에 깔리는 사각형·삼각형·원입니다. 꼭짓점을 끌어 모양을 바꾸고, 꼭짓점 안쪽의 작은 점으로 둥글게 만들고, 점선 상자로 크기를 바꿉니다. 핸들을 끌지 않고 클릭하면 값을 직접 입력할 수 있습니다. 도형마다 채우기와 테두리를 정합니다.
  - 모든 색은 하이라이트 색을 따르면서 불투명도만 정하거나, 직접 고른 색을 씁니다.
- **요소마다 다른 툴바**: 요소를 선택하면 그 요소만의 툴바가 하나 더 뜹니다. 글자 크기, 손·발 키뷰어, 도형 종류와 채우기·테두리를 바꿉니다. 손잡이를 끌어 원하는 곳에 두면 그 자리에 머뭅니다.
- **배치는 그대로**: 이미 놓아 둔 오버레이는 같은 값과 색, 위치를 가진 텍스트로 바뀝니다. 진행도·정확도·BPM은 하이라이트 색으로 점점 바뀌던 대신 하이라이트 색을 그대로 씁니다. 콤보는 "Perfect"와 숫자, 두 텍스트가 됩니다.
- **ElementNote 따로 열기**: 게임이 ElementNote를 macOS의 응용 프로그램 폴더(Launchpad, Spotlight)에 설치하고 Windows에서는 시작 메뉴 바로 가기를 만들어, 얼불춤 없이도 열 수 있습니다.
- **고친 점**: 게임 내 키뷰어 위에서도 툴바의 둥근 모서리가 깨지지 않고, 크기 % 같은 숫자 칸에 입력 커서가 보입니다.

### 어떤 파일을 받나요?

| 내 컴퓨터 | 받을 파일 |
| --- | --- |
| Windows 10 이상 | `Element-windows.zip` |
| macOS 11 이상 | `Element-macos.zip` |

Intel Mac에서도 모드는 동작하지만, 함께 들어 있는 ElementNote와 그것을 쓰는 게임 내 키뷰어는 아직 Apple 실리콘에서만 실행됩니다.

둘 중 하나만 받으면 됩니다. `Element.update.json`은 모드의 업데이터가 읽는 파일이고, "Source code" 압축 파일은 개발용이라 받지 않아도 됩니다.

### 설치

**필요한 것:** [UnityModManager](https://github.com/newman55/unity-mod-manager) 0.27 이상을 설치한 얼불춤. Windows에서 게임 내 키뷰어를 쓰려면 Microsoft Edge WebView2 런타임도 필요합니다(Windows 11에는 기본으로 있습니다).

1. 아래 **Assets**에서 내 컴퓨터에 맞는 zip을 받습니다.
2. 압축을 풀어 나온 `Element` 폴더를 얼불춤의 `Mods` 폴더에 넣습니다. Steam에서 게임을 오른쪽 클릭 → **관리** → **로컬 파일 보기**로 게임 폴더를 열 수 있습니다.
   - Windows: `...\steamapps\common\A Dance of Fire and Ice\Mods`. UnityModManager의 **Mods** 탭에 zip을 끌어다 놓아도 됩니다.
   - macOS: `~/Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods`
3. 게임을 켜고 **왼쪽 Alt + Tab**(macOS는 **⌥ + Tab**)을 누르면 설정이 열립니다.

macOS에서 모드의 라이브러리를 열 수 없다는 경고가 나오면, 다운로드 표시를 지우고 게임을 다시 켭니다.

```bash
xattr -dr com.apple.quarantine ~/"Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods/Element"
```
