## English

### What's new

- **Numbers that follow values**: any number in a text or shape can follow live values with + − × ÷: text size, width, height, rounding, border width and opacity. A shape as wide as current progress × 3 is a progress bar.
  - Values now hold one thing each: progress splits into start and current, time into its parts, and units like `%` are text you type. Texts from 1.1.0 are rewritten once so they look the same.
- **Redesigned text and shape editors**: both keep an input dock along the bottom with the formula and its result, every value by category, and a keypad with AC and Done. Click a value in, or drag it onto a number.
  - **Text**: the top bar has **Size**, **Text color** and **Grow from**. Click a value in the text to calculate with it.
  - **Shape**: **Add Element → Shape** asks for a square, triangle or circle. W sits under the shape and H beside it, and an arc outside each corner sets its rounding. The top bar has **Fill**, **Border**, **Border width** and **Grow from**. Dragging corners and resize handles are gone.
  - **Grow from** picks which point stays put when an element grows: one of nine, or Auto.
  - The color picker opens right above the keypad, and its opacity takes values too.
  - While a level plays behind the editor, autoplay for example, the preview shows live values.
  - Esc now saves like Done. Only **Cancel** leaves without saving.
- **Select several elements**: drag over empty space to select what lies fully inside, Cmd/Ctrl or Shift + click to add or remove one, Cmd/Ctrl + A for everything. They move together; with two or more selected the toolbar aligns them, and with three or more it also spaces them evenly.
  - On the canvas, texts and shapes now only move. Their size is set in the editor, opened by **Edit text** / **Edit shape** where the scale was. Sizes you already set stay.
- **A progress bar in the default layout**: three shapes under the top of the screen, filled in the highlight color as you play. The song title moves just below it. Your layout gets it once; delete it and it stays gone, and **Reset all** brings it back.
- **Shortcuts for effect presets**: each Effect Remover preset has a **Shortcut** tab. Press the shortcut to switch to that preset right away, except while you play.
- **Settings open with Left Ctrl + F9** (⌃ + F9 on macOS), since Left Alt + Tab also switches windows on Windows. If you kept the old default, it moves over once; a shortcut you picked stays.
- **Fixes**: song titles read the way the game shows them, with hidden parts left out and broken tags no longer shown as text. Spaces between values, like in the judgment row, survive a restart.

### Updating

From 1.0.0 or 1.1.0, the game updates itself the next time you start it. From ImplResourcePack 0.5.0 or earlier, follow [the 1.0.0 notes](https://github.com/KGH1113/Element/releases/tag/v1.0.0) first.

### Which file do I download?

| Your computer | Download |
| --- | --- |
| Windows 10 or later | `Element-windows.zip` |
| macOS 11 or later | `Element-macos.zip` |

On Intel Macs the mod runs, but the bundled ElementNote, and with it the in-game key viewer, needs Apple silicon for now.

You need only one of them. `Element.update.json` is read by the mod's updater, and the "Source code" archives are for developers; you don't need either.

### Install

**You need:** A Dance of Fire and Ice with [UnityModManager](https://github.com/newman55/unity-mod-manager) 0.27 or later. On Windows, the in-game key viewer also needs the Microsoft Edge WebView2 Runtime (Windows 11 has it).

1. Download the zip for your computer from **Assets** below.
2. Unzip it and move the `Element` folder into the game's `Mods` folder. In Steam, right-click the game → **Manage** → **Browse local files** to find it.
   - Windows: `...\steamapps\common\A Dance of Fire and Ice\Mods`. You can also drag the zip onto the **Mods** tab of UnityModManager.
   - macOS: `~/Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods`
3. Start the game and press **Left Ctrl + F9** (**⌃ + F9** on macOS) to open the settings.

If macOS says a library from the mod can't be opened, remove the download mark from the folder and start the game again:

```bash
xattr -dr com.apple.quarantine ~/"Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods/Element"
```

## 한국어

### 바뀐 점

- **값을 따라 움직이는 숫자**: 텍스트와 도형의 숫자는 모두 실시간 값과 + − × ÷로 계산할 수 있습니다. 글자 크기, 너비, 높이, 둥글기, 테두리 두께, 불투명도가 해당됩니다. 너비를 현재 진행도 × 3으로 하면 진행도 바가 됩니다.
  - 값은 이제 하나씩만 담습니다. 진행도는 시작 지점과 현재 진행도로, 시간은 각 부분으로 나뉘고, `%` 같은 단위는 직접 입력하는 글자입니다. 1.1.0에서 만든 텍스트는 같은 모양이 되도록 한 번 바뀝니다.
- **새 텍스트·도형 편집 화면**: 두 화면 모두 아래쪽에 입력 영역이 있습니다. 수식과 결과, 카테고리별 모든 값, AC와 완료가 있는 키패드입니다. 값을 클릭해 넣거나 숫자 위로 끌어다 놓습니다.
  - **텍스트**: 위쪽 막대에 **크기**, **글자 색**, **기준점**이 있습니다. 텍스트 안의 값을 클릭하면 그 값으로 계산합니다.
  - **도형**: **요소 추가 → 도형**에서 사각형·삼각형·원을 고릅니다. 도형 아래에 W, 옆에 H가 있고, 모서리 바깥의 호로 둥글기를 정합니다. 위쪽 막대에는 **채우기**, **테두리**, **테두리 두께**, **기준점**이 있습니다. 꼭짓점 끌기와 크기 조절 핸들은 없어졌습니다.
  - **기준점**은 요소가 커질 때 제자리에 남을 점입니다. 아홉 곳 중 하나나 자동을 고릅니다.
  - 색 선택기는 키패드 바로 위에 열리고, 불투명도에도 값을 넣을 수 있습니다.
  - 자동 플레이처럼 편집 화면 뒤에서 레벨이 재생 중이면 미리보기가 실시간 값을 보여 줍니다.
  - Esc를 누르면 완료처럼 저장됩니다. 저장하지 않고 나가려면 **취소**를 누릅니다.
- **여러 요소 선택**: 빈 곳을 드래그하면 영역 안에 완전히 들어온 요소가 선택되고, Cmd/Ctrl 또는 Shift + 클릭으로 하나씩 넣고 빼며, Cmd/Ctrl + A로 모두 고릅니다. 선택한 요소는 함께 움직이고, 두 개 이상이면 툴바에서 정렬하고, 세 개 이상이면 간격도 똑같이 맞춥니다.
  - 캔버스에서 텍스트와 도형은 이제 이동만 합니다. 크기는 원래 배율이 있던 자리의 **텍스트 편집** / **도형 편집**으로 여는 편집 화면에서 정합니다. 이미 정한 크기는 그대로입니다.
- **기본 배치의 진행도 바**: 화면 위쪽에 도형 세 개로 된 바가 있고, 플레이하면 하이라이트 색으로 찹니다. 곡 제목은 그 바로 아래로 옮겼습니다. 지금 쓰는 배치에도 한 번 추가되며, 지우면 다시 생기지 않고 **전체 초기화**로 되돌릴 수 있습니다.
- **이펙트 프리셋 단축키**: Effect Remover의 프리셋마다 **단축키** 탭이 생겼습니다. 단축키를 누르면 그 프리셋으로 바로 바뀝니다. 플레이 중에는 동작하지 않습니다.
- **설정은 왼쪽 Ctrl + F9로 엽니다**(macOS는 ⌃ + F9). 왼쪽 Alt + Tab은 Windows에서 창 전환과 겹치기 때문입니다. 예전 기본값을 그대로 쓰고 있었다면 한 번 바뀌고, 직접 정한 단축키는 그대로입니다.
- **고친 점**: 곡 제목이 게임에 보이는 그대로 나옵니다. 숨긴 부분은 빠지고, 깨진 태그가 글자로 보이지 않습니다. 판정 한 줄처럼 값 사이에 둔 공백이 재시작 후에도 남습니다.

### 업데이트

1.0.0이나 1.1.0에서는 다음에 게임을 켤 때 자동으로 업데이트됩니다. ImplResourcePack 0.5.0 이하에서 넘어온다면 먼저 [1.0.0 안내](https://github.com/KGH1113/Element/releases/tag/v1.0.0)를 따라 주세요.

### 어떤 파일을 받나요?

| 내 컴퓨터 | 받을 파일 |
| --- | --- |
| Windows 10 이상 | `Element-windows.zip` |
| macOS 11 이상 | `Element-macos.zip` |

Intel Mac에서도 모드는 동작하지만, 함께 들어 있는 ElementNote와 그것을 쓰는 게임 내 키뷰어는 아직 Apple 실리콘에서만 실행됩니다.

둘 중 하나만 받으면 됩니다. `Element.update.json`은 모드의 업데이터가 읽는 파일이고, "Source code" 압축 파일은 개발용이라 받지 않아도 됩니다.

### 설치

**필요한 것:** [UnityModManager](https://github.com/newman55/unity-mod-manager) 0.27 이상을 설치한 얼불춤. Windows에서 게임 내 키뷰어를 쓰려면 Microsoft Edge WebView2 런타임도 필요합니다(Windows 11에는 기본으로 있습니다).

1. 아래 **Assets**에서 내 컴퓨터에 맞는 zip을 받습니다.
2. 압축을 풀어 나온 `Element` 폴더를 얼불춤의 `Mods` 폴더에 넣습니다. Steam에서 게임을 오른쪽 클릭 → **관리** → **로컬 파일 보기**로 게임 폴더를 열 수 있습니다.
   - Windows: `...\steamapps\common\A Dance of Fire and Ice\Mods`. UnityModManager의 **Mods** 탭에 zip을 끌어다 놓아도 됩니다.
   - macOS: `~/Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods`
3. 게임을 켜고 **왼쪽 Ctrl + F9**(macOS는 **⌃ + F9**)를 누르면 설정이 열립니다.

macOS에서 모드의 라이브러리를 열 수 없다는 경고가 나오면, 다운로드 표시를 지우고 게임을 다시 켭니다.

```bash
xattr -dr com.apple.quarantine ~/"Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods/Element"
```
