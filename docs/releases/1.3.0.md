## English

### What's new

- **Profiles**: **General → Profiles** keeps several sets of your overlay, effect presets, Tweaks, highlight color and default font. Click a card to switch. The chatter blocker and settings like shortcuts stay the same across profiles.
  - Each card renames, duplicates, exports and deletes its profile. **New profile** starts from a first start's settings instead of a copy of the current ones.
  - Profiles export to and import from `.eprofile` files. If an imported profile uses fonts this PC lacks, Element asks which fonts to use instead.
  - Deleting or importing backs up your settings first, in the `Backups` folder.
- **Fonts**: pick the overlay's default font and each text's fonts from the fonts installed on your computer, or add TTF, OTF and TTC files. Added fonts are kept in `Mods/Element/Fonts`.
- **Key viewers in OrbitRender videos**: replay renders of TUFReplay recordings now show the hand and foot key viewers where they are in the game, scaled to the video. See [OrbitRender renders](https://github.com/KGH1113/Element/blob/main/docs/orbitrender.md).
  - Key counts continue from ElementNote's totals, and what the render presses is not added to them.
  - Normal renders leave the key viewers out.
  - While a render runs, FPS shows `-`, music time follows the video, and the song title shows the level name.
  - Elements you moved keep their place in the video, even when the video's shape differs from the game window's (a 16:10 screen, a 16:9 video).
- **Key viewers start at full size**: a key viewer you never moved, or reset, now shows at 100% on the bottom left, the hand viewer just above the bottom and the foot viewer to its right. Before, it showed at 50% in a bottom corner. If you never moved yours, it moves and grows once after this update. Key viewers you add in the layout editor start in the middle at 100%.
- **Edit key viewer**: select a key viewer in the layout editor and press **Edit key viewer**, double-click it or press Enter. ElementNote comes forward on the tab that viewer shows.
- **ElementNote is built on DmNote 2.1.0**: the app and its editing and saving engine now come from DmNote 2.1.0, so you can add sprites. Your key viewers look the same as before.
  - Your ElementNote settings move over once on first start, and the old file stays as `store.json.pre-migration.bak`.
- **Effect presets**: press a preset's shortcut again to turn effect removal off.
- **Chatter blocker**: it now follows KeyboardChatterBlocker's rule. It drops a press that comes within the threshold of the same key's last accepted press. The default threshold is 100 ms, and **Keys never blocked** lists keys it leaves alone. If you kept the old 20 ms default, it moves to 100 ms once.
- **Fixes**
  - Ghost keys keep the key you bind, and binding a key takes your next press.
  - Your judgment text choices are saved together with ADOFAI's own setting, and when the game quits.
  - The settings window and its shortcuts no longer stop when a selected element goes away with its scene.
  - Fonts without Latin letters draw labels in the system's Latin font instead of the built-in one.

### Updating

From 1.0.0, 1.1.0 or 1.2.0, the game updates itself the next time you start it. From ImplResourcePack 0.5.0 or earlier, follow [the 1.0.0 notes](https://github.com/KGH1113/Element/releases/tag/v1.0.0) first.

### Which file do I download?

| Your computer | Download |
| --- | --- |
| Windows 10 or later | `Element-windows.zip` |
| macOS 11 or later | `Element-macos.zip` |

On Intel Macs the mod runs, but the bundled ElementNote, and with it the in-game key viewer, needs Apple silicon for now.

You need only one of them. `Element.update.json` is read by the mod's updater, and the "Source code" archives are for developers; you don't need either.

### Install

**You need:** A Dance of Fire and Ice with [UnityModManager](https://github.com/newman55/unity-mod-manager) 0.27 or later. On Windows, the in-game key viewer also needs the Microsoft Edge WebView2 Runtime (Windows 11 has it).

1. Download the zip for your computer from **Assets** below.
2. Unzip it and move the `Element` folder into the game's `Mods` folder. In Steam, right-click the game → **Manage** → **Browse local files** to find it.
   - Windows: `...\steamapps\common\A Dance of Fire and Ice\Mods`. You can also drag the zip onto the **Mods** tab of UnityModManager.
   - macOS: `~/Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods`
3. Start the game and press **Left Ctrl + F9** (**⌃ + F9** on macOS) to open the settings.

If macOS says a library from the mod can't be opened, remove the download mark from the folder and start the game again:

```bash
xattr -dr com.apple.quarantine ~/"Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods/Element"
```

## 한국어

### 바뀐 점

- **프로필**: **일반 → 프로필**에 오버레이, 이펙트 프리셋, Tweaks, 하이라이트 색, 기본 폰트를 묶은 설정을 여러 벌 둘 수 있습니다. 카드를 누르면 그 프로필로 바뀝니다. 채터 블로커와 단축키 같은 설정은 모든 프로필이 함께 씁니다.
  - 카드마다 이름 바꾸기, 복제, 내보내기, 삭제가 있습니다. **새 프로필**은 지금 설정을 복사하지 않고 처음 설치했을 때의 설정으로 시작합니다.
  - 프로필은 `.eprofile` 파일로 내보내고 가져옵니다. 가져온 프로필이 이 PC에 없는 폰트를 쓰면 대신 쓸 폰트를 묻습니다.
  - 삭제하거나 가져오기 전에 지금 설정을 `Backups` 폴더에 백업합니다.
- **폰트**: 오버레이 기본 폰트와 텍스트마다 쓸 폰트를 컴퓨터에 설치된 폰트에서 고르거나, TTF·OTF·TTC 파일을 추가해 쓸 수 있습니다. 추가한 폰트는 `Mods/Element/Fonts`에 보관됩니다.
- **OrbitRender 영상에 키뷰어**: TUFReplay 기록을 리플레이 렌더하면 손·발 키뷰어가 게임에서와 같은 자리에 영상 크기에 맞춰 들어갑니다. 자세한 내용은 [OrbitRender 렌더](https://github.com/KGH1113/Element/blob/main/docs/orbitrender.md)에 있습니다.
  - 키 카운트는 ElementNote에 쌓인 값에서 이어지고, 렌더 중에 눌린 횟수는 더해지지 않습니다.
  - 일반 렌더에는 키뷰어를 넣지 않습니다.
  - 렌더 중에는 FPS가 `-`로 보이고, 음악 시간은 영상을 따르며, 곡 제목은 레벨 이름으로 보입니다.
  - 직접 옮긴 요소는 게임 창과 영상의 화면비가 달라도(예: 16:10 화면, 16:9 영상) 영상에서 같은 자리에 놓입니다.
- **키뷰어가 원래 크기로 시작**: 옮긴 적 없거나 초기화한 키뷰어는 이제 왼쪽 아래에 100% 크기로 보입니다. 손 키뷰어는 바닥에서 조금 띄우고, 발 키뷰어는 그 오른쪽에 놓습니다. 전에는 아래 모서리에 50% 크기로 보였습니다. 키뷰어를 옮긴 적 없다면 업데이트 후 한 번 자리와 크기가 바뀝니다. 레이아웃 편집 화면에서 추가한 키뷰어는 화면 가운데에 100%로 놓입니다.
- **키뷰어 편집**: 레이아웃 편집 화면에서 키뷰어를 고르고 **키뷰어 편집**을 누르거나, 더블클릭하거나, Enter를 누르면 ElementNote가 그 키뷰어의 탭을 연 채 앞으로 나옵니다.
- **ElementNote가 DmNote 2.1.0 기반으로**: 앱과 편집·저장 엔진이 DmNote 2.1.0에서 왔고, 스프라이트를 추가할 수 있습니다. 키뷰어 모양은 전과 같습니다.
  - ElementNote 설정은 처음 켤 때 한 번 옮겨지고, 예전 파일은 `store.json.pre-migration.bak`으로 남습니다.
- **이펙트 프리셋**: 프리셋 단축키를 한 번 더 누르면 이펙트 제거가 꺼집니다.
- **채터 블로커**: 이제 KeyboardChatterBlocker와 같은 규칙으로 동작합니다. 같은 키를 마지막으로 받은 누름부터 임계값 안에 다시 누르면 버립니다. 기본 임계값은 100ms이고, **막지 않을 키**에 넣은 키는 거르지 않습니다. 예전 기본값 20ms를 그대로 쓰고 있었다면 한 번 100ms로 바뀝니다.
- **고친 점**
  - 고스트 키에 지정한 키가 그대로 유지되고, 키 지정은 다음에 누른 키를 받습니다.
  - 판정 텍스트 설정이 얼불춤의 설정과 함께, 그리고 게임을 끌 때 저장됩니다.
  - 고른 요소가 장면과 함께 사라져도 설정 창과 단축키가 멈추지 않습니다.
  - 라틴 문자가 없는 폰트는 라벨을 내장 폰트 대신 시스템의 라틴 폰트로 그립니다.

### 업데이트

1.0.0, 1.1.0, 1.2.0에서는 다음에 게임을 켤 때 자동으로 업데이트됩니다. ImplResourcePack 0.5.0 이하에서 넘어온다면 먼저 [1.0.0 안내](https://github.com/KGH1113/Element/releases/tag/v1.0.0)를 따라 주세요.

### 어떤 파일을 받나요?

| 내 컴퓨터 | 받을 파일 |
| --- | --- |
| Windows 10 이상 | `Element-windows.zip` |
| macOS 11 이상 | `Element-macos.zip` |

Intel Mac에서도 모드는 동작하지만, 함께 들어 있는 ElementNote와 그것을 쓰는 게임 내 키뷰어는 아직 Apple 실리콘에서만 실행됩니다.

둘 중 하나만 받으면 됩니다. `Element.update.json`은 모드의 업데이터가 읽는 파일이고, "Source code" 압축 파일은 개발용이라 받지 않아도 됩니다.

### 설치

**필요한 것:** [UnityModManager](https://github.com/newman55/unity-mod-manager) 0.27 이상을 설치한 얼불춤. Windows에서 게임 내 키뷰어를 쓰려면 Microsoft Edge WebView2 런타임도 필요합니다(Windows 11에는 기본으로 있습니다).

1. 아래 **Assets**에서 내 컴퓨터에 맞는 zip을 받습니다.
2. 압축을 풀어 나온 `Element` 폴더를 얼불춤의 `Mods` 폴더에 넣습니다. Steam에서 게임을 오른쪽 클릭 → **관리** → **로컬 파일 보기**로 게임 폴더를 열 수 있습니다.
   - Windows: `...\steamapps\common\A Dance of Fire and Ice\Mods`. UnityModManager의 **Mods** 탭에 zip을 끌어다 놓아도 됩니다.
   - macOS: `~/Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods`
3. 게임을 켜고 **왼쪽 Ctrl + F9**(macOS는 **⌃ + F9**)를 누르면 설정이 열립니다.

macOS에서 모드의 라이브러리를 열 수 없다는 경고가 나오면, 다운로드 표시를 지우고 게임을 다시 켭니다.

```bash
xattr -dr com.apple.quarantine ~/"Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods/Element"
```
