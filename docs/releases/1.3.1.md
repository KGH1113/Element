## English

### What's new

- **Key changes in ElementNote are saved again**: a key you change in ElementNote's properties panel is saved. Before, ElementNote showed "Applied to ADOFAI", but the old key came back when you switched tabs, and ElementNote refused to quit. If a key change still can't be saved, ElementNote shows the saved keys again and tells you.
- **Oversized key viewers can be scaled down again**: a key viewer scaled larger than the game screen shows at the largest size that fits, inside the screen. Before, it was pushed almost entirely off screen, and changing its scale did nothing.
- **TUFReplay replays show that run's values**: when you replay or render a run TUFReplay recorded, the overlay shows the attempts from when you played it, and ElementNote's key counts continue from that run's counts. What the replay presses is not added to your attempts or your ElementNote key counts. See [TUFReplay recordings](https://github.com/KGH1113/Element/blob/main/docs/tufreplay.md).
  - Runs recorded before this show `-` for attempts, and their key counts continue from your current ones.
  - Key counts are saved only if ElementNote was running while you recorded.
- **Replay videos are made by TUFReplay**: TUFReplay now runs replay renders itself, and OrbitRender records the video. Element hands TUFReplay the overlay and the key viewers. See [OrbitRender renders](https://github.com/KGH1113/Element/blob/main/docs/orbitrender.md).
- **TUFReplay and OrbitRender versions**: the two replay changes above need a TUFReplay newer than 1.1.0 and an OrbitRender newer than 2.7.0. Until those come out, replays work as in 1.3.0, except that replay videos are made without the key viewers.

### Updating

From 1.0.0 through 1.3.0, the game updates itself the next time you start it. From ImplResourcePack 0.5.0 or earlier, follow [the 1.0.0 notes](https://github.com/KGH1113/Element/releases/tag/v1.0.0) first.

### Which file do I download?

| Your computer | Download |
| --- | --- |
| Windows 10 or later | `Element-windows.zip` |
| macOS 11 or later | `Element-macos.zip` |

On Intel Macs the mod runs, but the bundled ElementNote, and with it the in-game key viewer, needs Apple silicon for now.

You need only one of them. `Element.update.json` is read by the mod's updater, and the "Source code" archives are for developers; you don't need either.

### Install

**You need:** A Dance of Fire and Ice with [UnityModManager](https://github.com/newman55/unity-mod-manager) 0.27 or later. On Windows, the in-game key viewer also needs the Microsoft Edge WebView2 Runtime (Windows 11 has it).

1. Download the zip for your computer from **Assets** below.
2. Unzip it and move the `Element` folder into the game's `Mods` folder. In Steam, right-click the game → **Manage** → **Browse local files** to find it.
   - Windows: `...\steamapps\common\A Dance of Fire and Ice\Mods`. You can also drag the zip onto the **Mods** tab of UnityModManager.
   - macOS: `~/Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods`
3. Start the game and press **Left Ctrl + F9** (**⌃ + F9** on macOS) to open the settings.

If macOS says a library from the mod can't be opened, remove the download mark from the folder and start the game again:

```bash
xattr -dr com.apple.quarantine ~/"Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods/Element"
```

## 한국어

### 바뀐 점

- **ElementNote에서 바꾼 키가 다시 저장됨**: ElementNote 속성 패널에서 바꾼 키가 저장됩니다. 전에는 "얼불춤에 적용됨"이 떠도 탭을 옮기면 예전 키로 돌아갔고, ElementNote를 끌 수 없었습니다. 그래도 키 변경을 저장하지 못하면 저장된 키로 되돌리고 알려 줍니다.
- **너무 크게 키운 키뷰어를 다시 줄일 수 있음**: 게임 화면보다 크게 키운 키뷰어는 화면에 들어가는 가장 큰 크기로 화면 안에 보입니다. 전에는 거의 다 화면 밖으로 밀려났고, 크기를 바꿔도 그대로였습니다.
- **TUFReplay 리플레이에 그 플레이의 값**: TUFReplay가 기록한 플레이를 다시 보거나 영상으로 만들면, 오버레이는 그 플레이를 할 때의 시도 횟수를 보여 주고 ElementNote 키 카운트는 그 플레이의 카운트에서 이어집니다. 리플레이가 누른 키는 내 시도 횟수와 ElementNote 키 카운트에 더해지지 않습니다. 자세한 내용은 [TUFReplay 기록](https://github.com/KGH1113/Element/blob/main/docs/tufreplay.md)에 있습니다.
  - 이 업데이트 전에 녹화한 기록은 시도 횟수가 `-`로 보이고, 키 카운트는 지금 값에서 이어집니다.
  - 키 카운트는 녹화할 때 ElementNote가 켜져 있었을 때만 저장됩니다.
- **리플레이 영상은 TUFReplay가 만듦**: 이제 TUFReplay가 리플레이 렌더를 직접 진행하고, OrbitRender는 영상을 녹화합니다. 오버레이와 키뷰어는 Element가 TUFReplay에 넘깁니다. 자세한 내용은 [OrbitRender 렌더](https://github.com/KGH1113/Element/blob/main/docs/orbitrender.md)에 있습니다.
- **필요한 TUFReplay·OrbitRender 버전**: 위의 리플레이 변경 두 가지는 1.1.0보다 새 TUFReplay와 2.7.0보다 새 OrbitRender가 필요합니다. 두 모드의 새 버전이 나오기 전에는 리플레이가 1.3.0처럼 동작하고, 리플레이 영상에는 키뷰어가 들어가지 않습니다.

### 업데이트

1.0.0부터 1.3.0까지는 다음에 게임을 켤 때 자동으로 업데이트됩니다. ImplResourcePack 0.5.0 이하에서 넘어온다면 먼저 [1.0.0 안내](https://github.com/KGH1113/Element/releases/tag/v1.0.0)를 따라 주세요.

### 어떤 파일을 받나요?

| 내 컴퓨터 | 받을 파일 |
| --- | --- |
| Windows 10 이상 | `Element-windows.zip` |
| macOS 11 이상 | `Element-macos.zip` |

Intel Mac에서도 모드는 동작하지만, 함께 들어 있는 ElementNote와 그것을 쓰는 게임 내 키뷰어는 아직 Apple 실리콘에서만 실행됩니다.

둘 중 하나만 받으면 됩니다. `Element.update.json`은 모드의 업데이터가 읽는 파일이고, "Source code" 압축 파일은 개발용이라 받지 않아도 됩니다.

### 설치

**필요한 것:** [UnityModManager](https://github.com/newman55/unity-mod-manager) 0.27 이상을 설치한 얼불춤. Windows에서 게임 내 키뷰어를 쓰려면 Microsoft Edge WebView2 런타임도 필요합니다(Windows 11에는 기본으로 있습니다).

1. 아래 **Assets**에서 내 컴퓨터에 맞는 zip을 받습니다.
2. 압축을 풀어 나온 `Element` 폴더를 얼불춤의 `Mods` 폴더에 넣습니다. Steam에서 게임을 오른쪽 클릭 → **관리** → **로컬 파일 보기**로 게임 폴더를 열 수 있습니다.
   - Windows: `...\steamapps\common\A Dance of Fire and Ice\Mods`. UnityModManager의 **Mods** 탭에 zip을 끌어다 놓아도 됩니다.
   - macOS: `~/Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods`
3. 게임을 켜고 **왼쪽 Ctrl + F9**(macOS는 **⌃ + F9**)를 누르면 설정이 열립니다.

macOS에서 모드의 라이브러리를 열 수 없다는 경고가 나오면, 다운로드 표시를 지우고 게임을 다시 켭니다.

```bash
xattr -dr com.apple.quarantine ~/"Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods/Element"
```
