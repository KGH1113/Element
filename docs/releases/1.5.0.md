## English

### What's new

- **A text's color can follow a value**: in the text editor, **Animate → Color by value** changes the color as a value changes, such as X-Accuracy turning to the highlight color at 100 or progress blending toward it through a level. The color changes smoothly or at once, along a band you edit. See [Overlay elements](https://github.com/KGH1113/Element/blob/main/docs/features/overlay-elements.md#color-by-value).
- **Any value can grow when it changes**: **Animate → Grow when it changes** makes a value grow for a moment each time what it shows changes. Before, only the combo did. Layouts from earlier versions keep their combos growing.
- **Rebuilt text and shape editors**
  - Properties are rows in a column right of the preview, above the keypad. The color picker, the font list and the grow points open in that column.
  - The color tool is laid out anew: a large color square on the left, what the color is made of and its numbers on the right.
  - Controls are opaque, so the overlay behind no longer shows through them, and editors use the screen's width up to its margins.
- **Values are easier to find**: values sit in categories with a search that takes Korean or English names ("xacc" finds X-Accuracy). Chips show their live value, and values other mods add gather under that mod's name.
- **ElementNote's redesigned editor and sidebar**: the hand and foot views are tabs in the window bar, the sidebar lists each element as it really looks, and settings sit one per line. See [Using ElementNote](https://github.com/KGH1113/Element/blob/main/docs/features/element-note-ux.md).
  - New key viewers start with Raining speed 450 and track height 300.
  - DM Note presets keep their 4K to 8K layouts, and Reset All keeps the viewer tabs (#11).
- **Each profile keeps its own key viewers**: switching, creating, duplicating, importing and exporting a profile carries every ElementNote hand and foot key viewer and each key's press count. See [Profiles](https://github.com/KGH1113/Element/blob/main/docs/features/profiles.md).
- **In-game key viewers show the moment a play starts**: before, they loaded when a play started, so on slow PCs they appeared seconds in, and again after every restart. Record mode now hides them without unloading them, so they show at once when it is turned off.
- **Key viewers in replay videos on Windows**: they are drawn about twice as fast, and at the video's resolution. Before, they were captured smaller and stretched, which blurred the keys.
- **Effect Remover**
  - **Hitbox decorations** is its own option. Decorations that decide where the planet dies stay when you remove decorations, so Remove All no longer changes how a map plays.
  - **Track animations** keeps the map's opening tile appearance and hides passed tiles at once, as Enhanced Effect Remover does.
- **Other mods can add to the overlay**: a mod built with ElementKit adds its own values and overlay elements, and you place and edit them in Element like its own. See [ElementKit](https://github.com/KGH1113/Element/blob/main/ElementKit/README.md).
- **Fixes**
  - The settings window and the layout editor stay out of videos: they don't open while a video renders, and one already open closes. Effect preset shortcuts wait until the render ends.
  - A render cancelled while its key viewer videos finish no longer fails the next render.
  - In fullscreen at a lower resolution, in-game key viewers no longer cover the layout editor's panels.
  - Turning Element off gives the game its own key limiter keys back. Before, they came back only after restarting the game.
  - A hint shows right next to the control you point at, and a button no longer stays lit after you leave its page and come back.

### With TUFReplay and OrbitRender

Replays and replay videos need **TUFReplay 1.3.0 or later** and **OrbitRender 2.9.0 or later**. With an older TUFReplay, replay videos have no Element overlay or key viewers, and replays don't show their run's attempts and key counts.

### Updating

From 1.0.0 through 1.4.0, the game updates itself the next time you start it. From ImplResourcePack 0.5.0 or earlier, follow [the 1.0.0 notes](https://github.com/KGH1113/Element/releases/tag/v1.0.0) first.

### Which file do I download?

| Your computer | Download |
| --- | --- |
| Windows 10 or later | `Element-windows.zip` |
| macOS 11 or later | `Element-macos.zip` |

On Intel Macs the mod runs, but the bundled ElementNote, and with it the in-game key viewer, needs Apple silicon for now.

You need only one of them. `Element.update.json` is read by the mod's updater, and the "Source code" archives are for developers; you don't need either.

### Install

**You need:** A Dance of Fire and Ice with [UnityModManager](https://github.com/newman55/unity-mod-manager) 0.27 or later. On Windows, the in-game key viewer also needs the Microsoft Edge WebView2 Runtime (Windows 11 has it).

1. Download the zip for your computer from **Assets** below.
2. Unzip it and move the `Element` folder into the game's `Mods` folder. In Steam, right-click the game → **Manage** → **Browse local files** to find it.
   - Windows: `...\steamapps\common\A Dance of Fire and Ice\Mods`. You can also drag the zip onto the **Mods** tab of UnityModManager.
   - macOS: `~/Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods`
3. Start the game and press **Left Ctrl + F9** (**⌃ + F9** on macOS) to open the settings.

If macOS says a library from the mod can't be opened, remove the download mark from the folder and start the game again:

```bash
xattr -dr com.apple.quarantine ~/"Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods/Element"
```

## 한국어

### 바뀐 점

- **값을 따라 바뀌는 글자 색**: 텍스트 편집기의 **애니메이션 → 값에 따라 색 바꾸기**를 켜면 값이 바뀔 때 글자 색도 바뀝니다. 절대정확도가 100이 되면 하이라이트 색이 되거나, 진행도를 따라 하이라이트 색으로 물들게 할 수 있습니다. 색은 부드럽게 또는 한 번에 바뀌고, 띠 위에서 직접 편집합니다. 자세한 내용은 [오버레이 요소](https://github.com/KGH1113/Element/blob/main/docs/features/overlay-elements.md#color-by-value)에 있습니다.
- **어떤 값이든 바뀔 때 커지게**: **애니메이션 → 값이 바뀔 때 커지기**를 켜면 그 값이 바뀔 때마다 잠깐 커졌다 돌아옵니다. 전에는 콤보만 그랬습니다. 이전 버전에서 만든 배치의 콤보는 그대로 커집니다.
- **새로 만든 텍스트·도형 편집기**
  - 속성이 미리보기 오른쪽, 키패드 위의 열에 한 줄씩 놓입니다. 색 선택기, 폰트 목록, 기준점도 그 열에서 열립니다.
  - 색 도구의 배치가 바뀌었습니다. 왼쪽에 큰 색 사각형, 오른쪽에 색의 구성과 숫자가 있습니다.
  - 컨트롤이 불투명해져 뒤의 오버레이가 비치지 않고, 넓은 화면에서는 편집기가 화면 여백까지 넓어집니다.
- **값을 찾기 쉬워짐**: 값이 카테고리로 나뉘고, 한글이나 영어 이름으로 검색할 수 있습니다("xacc"로 절대정확도를 찾습니다). 칩에 지금 값이 보이고, 다른 모드가 추가한 값은 그 모드 이름 아래에 모입니다.
- **새로 디자인한 ElementNote 편집기와 사이드바**: 손·발 뷰를 창 위쪽 탭으로 오가고, 사이드바는 요소를 실제 모습 그대로 보여 주며, 설정은 한 줄에 하나씩 놓입니다. 자세한 내용은 [ElementNote 사용법](https://github.com/KGH1113/Element/blob/main/docs/features/element-note-ux.md)에 있습니다.
  - 새 키뷰어는 레이닝 속도 450, 트랙 높이 300으로 시작합니다.
  - DM Note 프리셋의 4K~8K 배치가 유지되고, 설정을 초기화해도 뷰어 탭이 남습니다(#11).
- **프로필마다 키뷰어를 따로 저장**: 프로필을 바꾸거나 만들고, 복제하고, 가져오고 내보낼 때 ElementNote의 손·발 키뷰어 전체와 키별 누른 횟수가 함께 따라갑니다. 자세한 내용은 [프로필](https://github.com/KGH1113/Element/blob/main/docs/features/profiles.md)에 있습니다.
- **게임 내 키뷰어가 플레이 시작과 함께 보임**: 전에는 플레이가 시작될 때 키뷰어를 불러와서, 느린 PC에서는 몇 초 뒤에야 보였고 재시작할 때마다 반복됐습니다. 녹화 모드도 키뷰어를 내리지 않고 숨기기만 하므로, 끄면 바로 보입니다.
- **Windows 리플레이 영상의 키뷰어**: 약 두 배 빠르게, 영상 해상도 그대로 그립니다. 전에는 작게 찍은 뒤 늘려서 키가 흐릿했습니다.
- **Effect Remover**
  - **히트박스 장식**이 따로 옵션이 되었습니다. 행성이 죽는 위치를 정하는 장식은 장식을 제거해도 남으므로, Remove All이 맵의 플레이 방식을 바꾸지 않습니다.
  - **타일 등장·퇴장**은 Enhanced Effect Remover처럼 맵의 처음 타일 모습을 유지하고, 밟은 타일은 바로 사라지게 합니다.
- **다른 모드가 오버레이에 요소를 추가**: ElementKit으로 만든 모드는 자기 값과 오버레이 요소를 추가할 수 있고, Element의 요소처럼 배치하고 편집합니다. 자세한 내용은 [ElementKit](https://github.com/KGH1113/Element/blob/main/ElementKit/README.md)에 있습니다.
- **고친 점**
  - 설정 창과 레이아웃 편집 화면이 영상에 찍히지 않습니다. 영상을 렌더하는 동안에는 열리지 않고, 열려 있던 것은 닫힙니다. 이펙트 프리셋 단축키도 렌더가 끝날 때까지 기다립니다.
  - 키뷰어 영상을 마무리하는 중에 렌더를 취소해도 다음 렌더가 실패하지 않습니다.
  - 낮은 해상도의 전체화면에서 게임 내 키뷰어가 레이아웃 편집 화면의 패널을 덮지 않습니다.
  - Element를 끄면 얼불춤의 키 리미터 키가 원래대로 돌아옵니다. 전에는 게임을 다시 켜야 했습니다.
  - 힌트가 가리킨 컨트롤 바로 옆에 뜨고, 페이지를 나갔다 돌아와도 버튼이 켜진 채로 남지 않습니다.

### TUFReplay·OrbitRender와 함께 쓸 때

리플레이와 리플레이 영상에는 **TUFReplay 1.3.0 이상**과 **OrbitRender 2.9.0 이상**이 필요합니다. 그보다 오래된 TUFReplay에서는 리플레이 영상에 Element 오버레이와 키뷰어가 나오지 않고, 리플레이에 그 플레이의 시도 횟수와 키 카운트가 표시되지 않습니다.

### 업데이트

1.0.0부터 1.4.0까지는 다음에 게임을 켤 때 자동으로 업데이트됩니다. ImplResourcePack 0.5.0 이하에서 넘어온다면 먼저 [1.0.0 안내](https://github.com/KGH1113/Element/releases/tag/v1.0.0)를 따라 주세요.

### 어떤 파일을 받나요?

| 내 컴퓨터 | 받을 파일 |
| --- | --- |
| Windows 10 이상 | `Element-windows.zip` |
| macOS 11 이상 | `Element-macos.zip` |

Intel Mac에서도 모드는 동작하지만, 함께 들어 있는 ElementNote와 그것을 쓰는 게임 내 키뷰어는 아직 Apple 실리콘에서만 실행됩니다.

둘 중 하나만 받으면 됩니다. `Element.update.json`은 모드의 업데이터가 읽는 파일이고, "Source code" 압축 파일은 개발용이라 받지 않아도 됩니다.

### 설치

**필요한 것:** [UnityModManager](https://github.com/newman55/unity-mod-manager) 0.27 이상을 설치한 얼불춤. Windows에서 게임 내 키뷰어를 쓰려면 Microsoft Edge WebView2 런타임도 필요합니다(Windows 11에는 기본으로 있습니다).

1. 아래 **Assets**에서 내 컴퓨터에 맞는 zip을 받습니다.
2. 압축을 풀어 나온 `Element` 폴더를 얼불춤의 `Mods` 폴더에 넣습니다. Steam에서 게임을 오른쪽 클릭 → **관리** → **로컬 파일 보기**로 게임 폴더를 열 수 있습니다.
   - Windows: `...\steamapps\common\A Dance of Fire and Ice\Mods`. UnityModManager의 **Mods** 탭에 zip을 끌어다 놓아도 됩니다.
   - macOS: `~/Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods`
3. 게임을 켜고 **왼쪽 Ctrl + F9**(macOS는 **⌃ + F9**)를 누르면 설정이 열립니다.

macOS에서 모드의 라이브러리를 열 수 없다는 경고가 나오면, 다운로드 표시를 지우고 게임을 다시 켭니다.

```bash
xattr -dr com.apple.quarantine ~/"Library/Application Support/Steam/steamapps/common/A Dance of Fire and Ice/Mods/Element"
```
